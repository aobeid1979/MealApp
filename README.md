# 🍽️ MealApp

MealApp is a full-stack web application that helps users plan meals, manage recipes, and generate smart shopping lists.

---

## 🚀 Features

### 👤 User

* Browse recipes
* View recipe details
* Adjust servings
* Add to meal plan
* Generate shopping list
* Manage shopping list (group, rename, check/uncheck)
* Add favorite recipes
* View profile

### 🛠️ Admin

* Manage categories
* Manage ingredient categories
* Manage ingredients
* Manage units
* Create and manage recipes
* Manage recipe ingredients, steps, and tools

---

## 🧱 Tech Stack

### Backend

* ASP.NET Core Web API (.NET 8)
* Entity Framework Core
* SQL Server
* JWT Authentication

### Frontend

* Next.js 15
* React
* Tailwind CSS

---

## 📁 Project Structure

```
MealApp/
 ├── backend/    # ASP.NET Core API
 └── frontend/   # Next.js app
```

---

## ⚙️ Getting Started

### Backend

```bash
cd backend
dotnet run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
